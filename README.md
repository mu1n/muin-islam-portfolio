## 🚀 Quick Start

### Option 1: One-Click Launch (Windows)
Double-click `start.bat`. It will launch the local server and open your browser automatically at `http://localhost:5050`.

### Option 2: Terminal / Node.js
```bash
cd C:\Users\User\Downloads\oliver-boyle-site
npm start
# or: node server.js
```
Open **[http://localhost:5050](http://localhost:5050)** in your browser.

---

## 🚢 Deployment Options

This codebase is ready for immediate deployment to any static hosting service or cloud provider:

1. **Vercel**: Run `vercel` or link to GitHub repository. `vercel.json` is already configured for clean URLs.
2. **Netlify**: Drag and drop the folder into Netlify Drop, or connect via Git. `_redirects` is already included.
3. **GitHub Pages / Cloudflare Pages**: Push to repository and enable Pages with root directory.
4. **Node / Docker**: Run `node server.js` on port `5050` or set `PORT=80` environment variable.
